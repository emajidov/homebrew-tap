# emajidov/homebrew-tap

Homebrew casks for apps by [@emajidov](https://github.com/emajidov).

## KeyBridge
Use Windows and Linux Ctrl keyboard shortcuts on your Mac. See [KeyBridge](https://github.com/emajidov/keybridge).

```bash
brew install --cask emajidov/tap/keybridge
```

Update with `brew upgrade --cask keybridge`. Uninstall with `brew uninstall --cask keybridge` (add `--zap` to also remove settings).

The cask is updated automatically when a new KeyBridge release is published.
